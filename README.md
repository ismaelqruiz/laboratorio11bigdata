# Laboratorio 11 - Infraestructura Big Data como Código

## Curso
Business Intelligence and Big Data

## Descripción
Implementación de una plataforma Big Data local utilizando Terraform y Floci para aprovisionar infraestructura compatible con AWS.

## Arquitectura
- Terraform: Infrastructure as Code.
- Floci: emulación local de servicios AWS.
- Amazon S3: almacenamiento Data Lake.
- AWS Glue Data Catalog: catálogo de datos por dominio.
